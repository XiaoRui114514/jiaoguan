## 本地运行

```powershell
node tools/build-release.cjs
node tools/check-release.cjs
node tools/serve-release.cjs
```

浏览器打开 `http://127.0.0.1:5174/`。服务器只提供 `dist/`，修改源码或资源后需重新构建。构建会校验资源存在性和美术审核哈希，失败时按诊断处理后再发布。

| 操作 | 按键 |
|---|---|
| 推进对白 | 点击场景或下一句；空格、Enter、右方向键 |
| 暂停菜单 / 关闭当前窗口 | Esc |
| 自动 / 快进 | A / S，再按一次停止 |
| 历史 / 隐藏对白 | L / H |
| 存档 / 读档 | Shift+S / Shift+L |
| 鉴赏切换 | 打开 CG 后使用左右方向键或界面按钮 |

Auto 和 Skip 遇到选择、暂停菜单或历史窗口会停止；隐藏页面也停止推进。设置可调整音乐与音效音量、逐字间隔、自动等待、字号和动画，并提供全屏控制。

手机窄屏自动显示横屏游戏，竖向窗口也会旋转完整画面；把手机横过来后恢复正常横向显示。

## 存档与升级

4.2.2 使用当前浏览器、当前网址下的 `Jiaoguan.v4.` 本地存储：六个手动槽和一个独立自动槽。自动记录不会覆盖手动记录，标题显示最近自动保存的章节；“继续”读取时间最新的有效记录。

自动保存覆盖新 ACT、选择及选择完成、关键变量、重要场景 / CG 节点、20 秒周期和页面隐藏 / 关闭。完整快照保存引擎状态与历史、章节、行号、bond、flags、已完成剧情段、玩家选择、人物、背景、BGM、已解锁 CG、时间与版本；画面右上角提示约一秒。

玩家选择记录保留选项键、选项文字、来源场景 / 行号与时间；已离开的剧情段记录完成章节与时间。读取存档会恢复这些记录，缺少新字段的早期 4.0 档以空记录继续读取。schema 仍为 4；兼容 4.0.0 / 4.1.0 / 4.2.0 / 4.2.1 记录，读取后及新保存的快照版本更新为 4.2.2。

3.0 的设置和已解锁旧 CG 会迁移，旧进度仍保留在原存储空间。4.0 剧情已扩写，旧行号不能准确对应，需从新游戏开始；读档页提供说明。损坏或不兼容的记录会被拒绝并提示。浏览器禁止存储时可临时游玩并保存到本次页面内，刷新后可能丢失。

## 项目结构

- `index.html` — 页面骨架
- `js/resources.js` — 角色与资源注册
- `js/script.js` — 完整剧情、ACT、选择、站位和动作
- `js/stage.js` — 场景、人物、CG 和音频演出辅助
- `js/main.js`、`js/storage.js`、`js/ui.js` — 推进、自动档、存读档和界面
- `js/audio.js` — 环境声交叉淡化、界面音效与后台暂停
- `css/game.css` — 校园视觉小说皮肤与站位层级
- `tokens.css` — 统一视觉变量
- `assets/characters/`、`assets/backgrounds/`、`assets/cg/`、`assets/thumbnails/`、`assets/audio/` — 已登记游戏资源
- `vendor/monogatari/` — Monogatari v2.8.0 引擎与许可证
- `tools/build-release.cjs`、`tools/serve-release.cjs` — 构建与本地预览
